Вывод:
Последовательно числа от 1 до 8 в случайном порядке.

Значения отправляются в канал с случайной задержкой. После отправки всех значений канал закрывается.
Затем объединяются два канала в один. Если из канала a приходит значение (case v, ok := <-a), оно отправляется в c. Если a закрывается (ok == false), канал a устанавливается в nil, и в дальнейшем select его игнорирует. Аналогично для канала b.
Главная функция main:
Создает два канала a и b с числами [1, 3, 5, 7] и [2, 4, 6, 8] соответственно.
Объединяет их в канал c с помощью merge.
Читает значения из c и выводит их.
